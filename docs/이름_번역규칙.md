# 인물·병기 이름 번역 규칙 (하스피 지시 2026-11-07: 패러디가 많으니 일관된 규칙으로 직접 번역, TSV 에 넣지 않음)

번역표: work/text/names_ko.tsv (종류·위치·한글). 원본표: work/text/names_jp.tsv (원문 바이트·칸 여유).

## 1. 일본어 소리 옮기기
- 일본어 고유명사는 «거센소리»: か행 ㅋ, た행 ㅌ, つ 츠, ちゃ 차, ん 받침 ㄴ. 장음은 적지 않는다(コウ→코, ユウ→유, オー→오).
- 말장난 낱말(의성어·유행어·음식 등)은 뜻을 옮기지 않고 소리대로 적는다(ヨイヨイ→요이요이, レイメン→레이멘).
- 단, 이름 안 «평범한 낱말»은 뜻을 옮긴다: 紙→종이, 刑事→형사, 樫の木→떡갈나무, 隊→대, 式→식, 爆→폭, 女帝→여제, 世→세, 号→호, 君→군, ちゃん→짱.

## 2. 실존 인물·실제 병기 패러디
- 원본 대상의 한국 통용 표기를 바탕으로 같은 비틀기를 한다: ペンジェル・マンセル(나이절 만셀)→펭젤 만셀, ハン・ソーロン(한 솔로)→한 솔론, ジョン・ピンポン→존 핑퐁.
- 실제 병기 이름·영어 차용어는 한국 통용 외래어: セイバー 세이버, ファントム 팬텀, ファルコン 팔콘, ミラージュ 미라주, ラッキー 럭키, ジャイアント 자이언트.
- 형식 번호(Ｆ－１４, ＡＨ６４, Ｍｋ３ 등)는 그대로, 원문처럼 붙여 쓴다(번호와 이름 사이 띄우지 않음).

## 3. 나라 상징 접두어(나라 브랜드 펀)
- ペン(펭귄) → **펭**: ペン太郎 → 펭타로, ペンドリュー → 펭드루.
- ニャン·ニャー·猫(고양이) → **냥**: ニャンニャン式 → 냥냥식, 猫戦艦 → 냥전함, メカニャン → 메카냥, ニャー帝国 → 냥 제국, 帝王ニャー・ムー → 제왕 냥 무(하스피 «냥으로 통일»). 낱말 속 ニャ 소리(プラニャーニ 등 이름)는 냐.
- ワン(개 짖는 소리) → **멍**: ワン田 → 멍다, ワン玉三郎 → 멍타마사부로.
- ポチ·シロ·クロ·ケン·イヌ·ブル(개 이름·개)는 소리대로: 포치·시로·쿠로·켄·이누·부루 (원래 패러디 이름 모양 유지 — 이누에 켄자부로 = 오에 겐자부로).
- こいつ·あいつ·そいつ·どいつ → **이녀석·저녀석·그녀석·어느녀석**(하스피 확정).

## 4. 한자 성(중국 쪽 인물)
- 한자 성은 한국 한자음: 張 장, 曹 조, 黄 황, 陳 진, 王 왕, 劉 유, 孫 손, 呉 오, 李 이, 周 주, 関 관, 馬 마, 史 사, 呂 여, 典 전, 諸葛亮 제갈량, 毛 모, 超 초, 董 동, 方 방, 猿 원. 뒤 가타카나는 1번 규칙.
- 일본 쪽 한자 이름(개 나라)은 일본어 읽기 그대로(1번): 山田 야마다, 太郎 타로, 渋谷 시부야.

## 5. 길이
- 원문 글자 수 이하를 기본으로 한다(한글 1자 = 2바이트 = 일본어 1자).
- 넘치는 것은 칸 여유(이름 칸 뒤 0 바이트)와 화면 폭(원문 최장 12자)을 확인한 뒤 허용하고 목록에 남긴다.
- 띄어쓰기: 원문에 «・»나 전각 공백이 있던 자리만 띄운다.
